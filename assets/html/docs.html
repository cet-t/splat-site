splapi3 — Discord Embed API

Splatoon3 スケジュール情報を Discord OGP 埋め込み用 HTML として返す API

概要

このサービスは spla3.yuu26.com API からスケジュール情報を取得し、Discord のリンク展開（OGP）に最適化した HTML ページを返す。 URL を Discord に貼るとステージ画像・ルール名・開催時間がカード表示される。

ベースURL: https://splat.site

エンドポイント一覧

GET/

疎通確認用。"Hello, World!" を返す。

GET/open = /open/now

バンカラマッチ（オープン）の現在開催中スケジュール。

GET/open/now

バンカラマッチ（オープン）の現在開催中スケジュール。

GET/open/next

バンカラマッチ（オープン）の次回以降のスケジュール。n パラメータで何回後かを指定。

GET/regular = /regular/now

レギュラーマッチの現在開催中スケジュール。

GET/regular/now

レギュラーマッチの現在開催中スケジュール。

GET/regular/next

レギュラーマッチの次回以降のスケジュール。n パラメータで何回後かを指定。

クエリパラメータ

名前 対象 型 説明
t 全エンドポイント u32 現状サーバー側で未使用（受理されるが出力に影響しない）
n（別名 i） /open/next, /regular/next u8 何回先の対戦かを指定。0 = 現在開催中（now と同じ）、 1 = 次回（省略時デフォルト）、2 = 次々回 ...

未知のクエリパラメータが付くとリクエストは拒否される（deny_unknown_fields）。

リクエスト例

GET /open/next?n=2
GET /regular/next?i=1
GET /regular/now

レスポンス

Content-Type: text/html。以下の情報を含む OGP メタタグ付き HTML を返す。

項目 内容
og:site_name splat.site
og:title ルール名（例: ガチエリア、ナワバリバトル）
og:description 開催時間帯（MM/DD HH:MM - MM/DD HH:MM）とステージ名一覧
og:image（複数） 各ステージのサムネイル画像URL
theme-color ルールに応じた色（ナワバリ: #00ff00、それ以外: #ffa500）

エラー時

対象スケジュールが存在しない、または n が範囲外の場合、本文 "ERROR" を200で返す （上流APIエラーやHTTPステータスでは表現されない点に注意）。

対応ルール

API キー 表示名 カラー
TURF_WAR ナワバリバトル #00ff00
AREA ガチエリア #ffa500
LOFT ガチヤグラ #ffa500
GOAL ガチホコバトル #ffa500
CLAM ガチアサリ #ffa500

データソース

上流API: https://spla3.yuu26.com/api/{{mode}}/{{schedule}}
mode は regular / bankara-open のいずれか（本サービスが公開する機能範囲）。
schedule は now または schedule（next エンドポイント使用時）。
